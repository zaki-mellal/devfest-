# DevFest 2026 — GDG Ghardaia

هذه نسخة منظمة من ملف HTML الأصلي، دون تعديل محتوى CSS أو JavaScript، مع الحفاظ على ترتيب تشغيلهما.

- `index.html`: الصفحة الرئيسية
- `css/style.css`: محتوى أقسام CSS الثلاثة الأصلية
- `js/main.js`: محتوى أقسام JavaScript الأربعة الأصلية
- `assets/`: ضع هنا الصور والشعارات بنفس المسارات والأسماء الأصلية

**ملاحظة:** الصور لم تكن مرفقة داخل مجلد مستقل، لذلك لم تُضمَّن في هذه النسخة. راجع `assets/FILES_NEEDED.txt` وضع ملفات الصور الأصلية في مساراتها قبل النشر. بعض الأيقونات مضمنة أصلًا في HTML ولا تحتاج ملفات منفصلة.

للمعاينة: افتح `index.html` محليًا. لنشر الموقع: ارفع محتويات المجلد إلى مستودع GitHub، ثم فعّل GitHub Pages إن كان مناسبًا لك.
